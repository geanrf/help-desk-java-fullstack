# Capturas do projeto

Adicione nesta pasta as imagens usadas pelo README principal:

- `login.png`
- `tickets.png`
- `ticket-details.png`
- `dashboard.png`
- `users.png`

Recomendações:

- use resolução consistente, preferencialmente 1440 × 900;
- capture somente dados demonstrativos;
- não exponha tokens, cabeçalhos de autorização, senhas, consoles ou variáveis de ambiente;
- mantenha o tema escuro e a mesma escala do navegador em todas as imagens;
- compacte os arquivos antes do commit para evitar aumentar desnecessariamente o repositório.
